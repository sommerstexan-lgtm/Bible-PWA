# NASB Study PWA – v2.1.0 (flat)

**Password:** `NASB-Study-1995-Private`

All files are at the root — no folders. This avoids the GitHub upload problem.

## Upload (simple)

1. Delete everything currently in your Bible-PWA repo.
2. Unzip this package.
3. You will see 13 files (no folders).
4. On GitHub → Add file → Upload files.
5. Select **all 13 files** and drag them in.
6. Commit.
7. Settings → Pages → main / (root) → Save.
8. Wait 1–2 minutes → open https://sommerstexan-lgtm.github.io/Bible-PWA/
9. Enter the password.

That is the entire process.
